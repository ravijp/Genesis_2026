# Judging — ARCHITECT JUDGE (T16, Stage 6)

**Judge role:** Architect judge. Axes: MVP buildability (`build`), 3-week-client-fit credibility (`fit3w`), demo strength (`demo`).
**Model tier:** opus (deep scrutiny per subagent-tiering rule).
**Date:** 2026-07-15.
**Order used:** odd-numbered clusters ascending (C01, C03, … C63), then even-numbered ascending (C02, C04, … C64), skipping the 4 PARKED (C41, C43, C51, C60). 60 clusters scored.

**Scoring frame.** `build`: walking skeleton by end of week 1 + eval design existing day 0 + fresh-machine reproducible. `fit3w`: file/export in-and-out advisory = 5; core-write / real-time stream / two-sided counterparty / missing-market precondition = penalized. `demo`: a visceral ≤5-min moment with synthetic seeded ground truth that a judge retells. Scores are on the **grounded** scope in grounding.md, not the (sometimes over-reaching) raw card; where the raw card claims more than the grounded MVP, that is noted, not penalized twice. Competition MVP = 2-3 people, ≤6 weeks; sizing gate = ≤1 L + ≤2 M across {agent roles, tools/integrations, UI surface, synthetic data, eval harness}.

Flags (`SIZING-VIOLATION`, `KILL-OBJECTION`) force rework, not averaging — raised only where credible.
